# Frontend

Web client for JDK ERP.

Not yet implemented. When scaffolding this, follow
[`docs/ENGINEERING_PRINCIPLES.md`](../docs/ENGINEERING_PRINCIPLES.md) —
in particular:

- treat UI visibility as usability only, never as security (Principle 3)
- one standard component library — buttons, forms, tables, filters,
  modals, alerts, badges, pagination, loading/empty/error states
  (Principle 6)
- consistent terminology, status colours and confirmation flows across
  every module (Principle 7)
